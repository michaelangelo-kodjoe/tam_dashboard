What users get from Download template. Click the sheet tabs. The Status cell D3 shows the dropdown; the date header shows the format hint.

Instructions sheetPlain sentences, read-only look. Opens first so people read it once; the import ignores it.
Accounts sheetSix columns. Account name is the only required one (amber underline, asterisk). Status is a dropdown; the date column has a format hint note on its header. Rows 2 to 501 are the import range.
Lists sheet (hidden)Holds the Status and Products lists that feed the dropdown and the products check. Hidden so it is not edited by accident; regenerated by the app on every download.
