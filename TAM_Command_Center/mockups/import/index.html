Account bulk import with duplicate detection: mockups

Static mockups with made-up data (Tue 13 Oct 2026). Core account fields only; similar names are flagged for confirmation, in the bulk import and when adding one account by hand. Same account fills blanks only. Nothing is written before Preview and an explicit Apply; Apply runs as one transaction after a safety backup and records audit events with source Bulk Import. Not built into the app.

1. Accounts page and import dialog: choose file

The Accounts page gains an Import accounts button beside Account. The dialog opens on step 1 with a drag-and-drop area, the .xlsx-only and 500-row limits, a Download template button and four plain rules (core fields only, similar names are confirmed one by one, blanks only, nothing written until Apply). A toggle at the bottom left shows the chosen-file state.

2. Template workbook

The downloaded .xlsx drawn as a spreadsheet with clickable tabs: Instructions, Accounts (Account name required, BPID, Products, Status dropdown, Next contact date with a YYYY-MM-DD hint, Notes) and the hidden Lists sheet that feeds the dropdown and the products check.

3. Preview

Counts for Valid, New, Updates, Needs review and Invalid, then a row-level table with a result badge and detail per row, filter tabs, and row-level validation errors under invalid rows. Exact name matches show as Update (fill blanks). Nothing is written yet.

4. Review duplicates

Interactive. A list of the 7 flagged rows and, for the selected one, the file row beside the matched account (an existing account or another row in the file), the match reasons, a similarity bar, what Same account would fill (blanks only) and what stays untouched, and the three choices. A progress count and bar track resolution; Apply stays disabled until all 7 are resolved.

Open

5. Result summary

After Apply: created, updated, skipped and overwritten counts (overwritten is always 0), the safety backup file taken first, the one-transaction note, the 36 audit events with source Bulk Import, blanks filled, and the list of skipped rows.

Open

6. Add one account, similar account found

The add-account dialog after clicking Add account with the name Web Ltd: an inline confirmation shows the existing Web Mgmt Ltd, why it matched, and three choices: Same account (opens the existing record), Different account (creates it) and Cancel. The Add account button stays disabled until one is chosen.
