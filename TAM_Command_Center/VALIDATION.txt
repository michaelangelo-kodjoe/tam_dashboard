4. DEPENDENCY NOTES (found while building)
   - server/requirements.txt pins websockets==17.2, which needs Python 3.11+, so
     "pip install -r server/requirements.txt" fails on Python 3.10 (supported minimum).
     The release requirements.txt drops the optional uvicorn[standard] extras (uvloop - no
     Windows wheels - httptools, watchfiles, websockets, python-dotenv, PyYAML) and all
     test-only packages. The app runs without them (smoke test on 3.10).
   - openpyxl (spec section 48) is not included because nothing in this build uses it yet.
